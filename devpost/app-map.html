Where things live

  • menu.json — dishes, prices, starting portions, ZiG rate, delivery zones. Edit this to run your own kitchen.
  • src/interpret.js — understanding only. Shona numbers in NUMBER_WORDS; Gemini prompt in geminiInterpret().
  • src/engine.js — the trust boundary: priceCart(), substitute(), findSuburb(), conversation stages in nextStage().
  • src/store.js — data/orders.json and data/stock.json; takeStock() is all-or-nothing.
  • test/engine.test.js — six checks that prove the kernel.

A practice to reuse

Let the model interpret, let code decide. Any time an LLM touches money, stock or IDs, have it return intent as JSON, then validate and compute in code — and write a test that tries to make it lie (“3 sadza for $1 each”).
